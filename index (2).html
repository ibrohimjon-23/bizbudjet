Sayt egasi uchun bir martalik sozlash

Ilovaning hamma qismi shu bitta faylda, maʼlumotlar bazasini oʻrnatuvchi ham. Xavfsiz qism — akkauntlar, doimiy hisob daftari, tahrirlash va oʻchirishni taqiqlovchi qoidalar — bepul Supabase loyihasida ishlaydi, chunki brauzerning oʻzi moliyaviy maʼlumotni himoya qila olmaydi. Beshta qadam taxminan 15 daqiqa oladi va faqat bir marta bajariladi. Sozlangan faylni GitHub’ga yuklaganingizdan keyin bu sahifa butunlay yoʻqoladi va sayt toʻgʻridan-toʻgʻri kirish sahifasidan ochiladi.

1

Supabase loyihasini yarating

supabase.com saytiga kiring va yangi loyiha yarating. Oʻzbekiston uchun Frankfurt (eu-central-1) hududi qulay. Maʼlumotlar bazasi parolini xavfsiz joyda saqlang.

Supabase’ni ochish
2

Maʼlumotlar bazasini oʻrnating

Quyidagi oʻrnatuvchidan nusxa oling, loyihangizda SQL Editor → New query ni oching, joylashtiring va Run tugmasini bosing. U jadvallar, oʻzgartirishni taqiqlovchi triggerlar, kirish qoidalari, xavfsiz saqlash funksiyalari va jonli sinxronlashni yaratadi. Qayta ishga tushirish xavfsiz — maʼlumot hech qachon oʻchmaydi.

SQL Editor’ni ochish
3

Faylni loyihangizga ulang

Supabase’da Project Settings → API (yoki API Keys) ni oching va Project URL hamda anon public yoki publishable kalitdan nusxa oling. Bu kalit ochiq boʻlishi uchun moʻljallangan: oʻzi yolgʻiz hech narsani oʻqiy ham, oʻzgartira ham olmaydi. Service-role (maxfiy) kalitni bu yerga hech qachon qoʻymang.

“Shu qurilmada saqlash” faqat shu brauzerda ishlaydi. Ikkala telefonda ishlashi uchun sozlangan faylni yuklab oling va uni GitHub’ga joylang (5-qadam).

4

Ikki akkauntni yarating

Faqat shu ikki login mavjud boʻlishi mumkin. Maʼlumotlar bazasi boshqa har qanday manzilni rad etadi va rollarni oʻzi belgilaydi.

OYBEK (Admin)oybek@bizbudget.local
IBROHIMJON (Foydalanuvchi)ibrohimjon@bizbudget.local

A usul, eng xavfsizi: Supabase’da Authentication → Users → Add user → Create new user ni oching, har bir manzilni boshlangʻich paroli bilan kiriting va Auto Confirm User belgisini qoʻying.

B usul, shu yerdan: vaqtincha Allow new users to sign up ni yoqing va Confirm email ni oʻchiring (Authentication → Sign In / Providers), soʻng ikkala akkauntni ketma-ket yarating. Ikkalasi yaratilgach, kalit yoqiq qolsa ham, baza boshqa roʻyxatdan oʻtishni rad etadi.

5

Himoyalang va ishga tushiring

  • Allow new users to sign up ni oʻchiring (agar Confirm email ni oʻzgartirgan boʻlsangiz, qayta yoqing).
  • Yuklab olingan, sozlangan index.html faylni bizbudget GitHub repozitoriyangizga yuklang (eskisining oʻrniga). GitHub Pages tayyor ilovani koʻrsatadi: birinchi kirish sahifasi ochiladi, bu sozlash sahifasi esa yoʻqoladi.
  • Ikkala telefonda kiring, keyin har biringiz Profil → Parolni oʻzgartirish orqali oʻz parolingizni qoʻying.
  • Zaxira: Supabase Pro har kuni avtomatik zaxira nusxa oladi (Database → Backups). Har qanday tarifda admin Admin paneldan toʻliq JSON zaxirani, hamma esa CSV yoki PDF hisobotlarni yuklab olishi mumkin.
Himoya qanday ishlaydi va uni qanday tekshirish mumkin

Brauzer hisob daftariga hech qachon toʻgʻridan-toʻgʻri yozmaydi. Har bir yozuv maʼlumotlar bazasidagi funksiya orqali oʻtadi: u kiritgan odamni tizimga kirgan akkauntdan oladi, server vaqtini qoʻyadi, bir vaqtda kelgan yozuvlarni birma-bir qayta ishlaydi va balansni manfiyga tushiradigan har qanday amalni rad etadi. PostgreSQL triggerlari tranzaksiyalar va faoliyat jurnalida UPDATE, DELETE va TRUNCATE’ni hamma uchun, hatto Supabase’ning admin kaliti uchun ham taqiqlaydi. Xatolar bekor qilish yozuvi bilan tuzatiladi; asl yozuv abadiy koʻrinib turadi.

Oʻzingiz tekshirish uchun birinchi yozuv paydo boʻlgach, SQL Editor’da quyidagilarni birma-bir ishga tushiring. Har biri BB_IMMUTABLE xatosi bilan rad etilishi kerak:

update public.transactions set amount = 1 where id = (select min(id) from public.transactions);
delete from public.transactions where id = (select min(id) from public.transactions);
truncate public.transactions;

Zaxiradan tiklash: Supabase Pro’da Database → Backups orqali tiklanadi. Aks holda Supabase CLI bilan olingan dump (supabase db dump) yangi loyihaga yuklanadi, soʻng shu fayl 3-qadamda qayta ulanadi.
